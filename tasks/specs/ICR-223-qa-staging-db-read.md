# ICR-223 — QA agents can read the staging databases (read-only)

- **Branch:** `chore/ICR-223-qa-staging-db-read` · **Commit type:** `chore` · **QA depth:** standard
- **Sensitive areas:** `env-secrets`, QA config, congregant PII (design gates: brainstorm + spec RESOLVED, Option B + PM changes)

## 1. Requirements

1. **R1 — Command.** `apps/admin/scripts/qa-db-read.ts` (logic in `apps/admin/src/lib/qa-db/`), run like `qa-auth`:
   `YOKE_QA_DB_ENV=<env> sh -c 'cd apps/admin && exec node --import tsx scripts/qa-db-read.ts <read|count|aggregate> --db <name> --collection <c> [--filter <json>] [--project <json>] [--sort <json>] [--limit n] [--pipeline <json>]'`
   Never via `pnpm run`/`pnpm exec` (exit code `2` must survive). Exit codes: `0` ok, `2` refused (policy/args, before any query), `1` unexpected failure. Contract id `yoke/qa-db-read@1`.
   Verbs: `read` (find), `count`, `aggregate` (`--pipeline <json>`). Any other verb → refused (`2`). Flags are restricted per verb.
2. **R2 — Db & collection guards (before any connect).** `YOKE_QA_DB_ENV` is required (no default) and must be an own property of `{ preview, previewAdmin, staging, stagingAdmin }`. Per-env `DB_NAME_ALLOW` must equal `.claude/config.json` → `qa.env.<env>.dbNameAllow` (`preview`: `^(website|ministry-admin)-(test|qa|e2e)$`; others: `^(website|ministry-admin)-(staging|test|qa|e2e)$`), enforced by test. Exact anchored regex rejects bare `website`, `ministry-admin`, `test`, `admin`, `local`, `config`, prototype keys (`constructor`, `__proto__`, `prototype`, `toString`), and case/whitespace variants. Default-deny `COLLECTION_ALLOW` (20 collections): `sections`, `belief_collections`, `event_banners`, `posts`, `sermons`, `bible_verses`, `authors`, `topics`, `seo_entries`, `globals`, `media`, `content_audit`, `pdf_jobs`, `likes`, `contact`, `broadcast_log`, `roles`, `rbacAudit`, `users`, `invites`.
3. **R3 — URI handling.** URI comes only from the environment — never argv, never printed. Variable selected strictly by DB prefix with no fallback: `website-*` → `WEBSITE_MONGODB_URI`, `ministry-admin-*` → `MONGODB_URI`. Refuse if missing or malformed (empty host rejected). Parse the db path: if present, it must equal `--db`; if absent (admin-staging URI has an empty path), an explicit allowlisted `--db` is required; never fall back to `test`.
4. **R4 — Read-only by construction.** `connectReadOnly` exposes only `find`/`count`/`aggregate`/`close` (`retryWrites: false`, `readPreference: "secondaryPreferred"`, `allowDiskUse: false`, `maxPoolSize: 2`, closes client on connect error). Strict stage allowlist: `$match`, `$project`, `$sort`, `$limit`, `$skip`, `$count`, `$group`, `$unwind`, plus a restricted 4-key plain-collection `$lookup` (`from` in `COLLECTION_ALLOW`, no `pipeline`/`let`). Refuse `$out`, `$merge`, `$unionWith`, `$graphLookup`, `$documents`, `$currentOp`, `$collStats`, `$function`, `$accumulator`, `$where`, `$expr`, `$facet`, `$set`, `$addFields`. Recursive `$`-operator allowlist scan across filters and stages; strict `0|1|true|false` projections; `$group` refuses references to masked fields; `maxTimeMS: 5000`; result cap `50`.
5. **R5 — Output scrub.** Envelope `{ contract, ok, db, collection, observedVia: "DB", count, docs, masked }` on stdout; diagnostics on stderr. Scrubber recursively masks denylisted keys (English + Spanish + accented + snake_case: `email`, `password*`, `token*`, `secret*`, `apiKey`, `cookie`, `phone`, `telefono`/`teléfono`, `address`, `direccion`/`dirección`, `firstName`/`lastName`/`fullName`/`displayName`, `nombre`, `apellido`, `birth*`, `dob`, `notes?`, `messages?`/`mensajes?`, `*uid`, `*ip*`) → `"[masked]"`. `name` is masked everywhere except `"QA "` test identities and system role names (`admin`/`leader`/`member`) on `roles`/`rbacAudit` (without `$lookup`). Linear-time regex pass masks emails, `mongodb(+srv)://` URIs, JWTs, and Bearer/Basic tokens in every string and key. Errors are fixed strings; driver text is never emitted.
6. **R6 — Config & discovery.** In `.claude/config.json`: remove nonexistent `mongoMcp: "mongodb-localhost"` from all four `qa.env.*` blocks (keep `dbNameAllow`), add per-env `dbReadNote` naming the command and doc path, and add root block `qaDb` (`contract`, `command`, `envSelector`, `uriVariables`, `readOnly: true`, `collections`, `doc`). Shared canon schema is untouched; proof via `ajv-cli@5.0.0 --spec=draft2020` and `validate-config.mjs --strict` → `0 errors`. Add short QA DB-read pointers in `CLAUDE.md` and `AGENTS.md`. Follow-up: first-class `qa.db` field in the canon schema so `qa-runner` receives it directly in its env block.
7. **R7 — Docs.** `docs/architecture/qa-db-read.md` + link from `docs/architecture/admin-qa-account.md`: command, allowed DBs, workstation setup (logged-in Vercel CLI only; no per-machine MCP/config), explicit env pull target from `--project idc-redentor-admin` for **both** `ministry-admin-*` (`MONGODB_URI`) and `website-*` (`WEBSITE_MONGODB_URI`) shredded after, PII masking + filter-probing residual risk, harness `perAC[].observedVia: "db"` lowercase note, and prohibition on locally registered write-capable Mongo MCP servers (`MDB_MCP_READ_ONLY=false`).
8. **R8 — Live proof.** On `previewAdmin`: QA role change on a `"QA "` role, then `read --db ministry-admin-staging --collection rbacAudit --filter …` returns the entry and QA records it as observed via DB (`perAC[].observedVia: "db"`). Needs the QA slot from `@coordinator`.

## 3. Checkpoints

1. Guard + parser + tests (red→green). 2. Wrapper + stage/operator scan + tests. 3. Scrubber + CLI + contract tests. 4. Config + validation. 5. Docs + agent pointers. 6. `type-check`/`lint`/`test`/`build`, validator fixes. 7. Live `previewAdmin` QA proof (with QA slot), then mark PR ready.

## 4. Out of scope
